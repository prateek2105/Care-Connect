\begin{sectionbox}{INTRODUCTION}
\small
\textbf{Object detection} jointly determines \emph{what} objects are present in an image
and \emph{where} they are, outputting bounding boxes and class labels.
Unlike classification, detection must handle an unknown number of objects at varying
scales and with potential overlap---making the task fundamentally harder.

The central tension in detector design is:
\begin{itemize}
  \item \textbf{Precision (mAP):} fewer misses, fewer false alarms, tight localization.
  \item \textbf{Speed (FPS / latency):} throughput for real-time and edge deployment.
\end{itemize}

\textbf{Thesis:} Detectors evolved from hand-crafted features through CNN-based
two-stage and one-stage pipelines to transformer-based set prediction,
each generation reshaping the speed--precision frontier.
\end{sectionbox}

% ---------------------------------------------------------------
\begin{sectionbox}{TRADITIONAL METHODS (PRE-2012)}
\small
\textbf{Core idea:} exhaustive region enumeration + engineered features + shallow classifiers.

\begin{itemize}
  \item \textbf{Viola--Jones (2001):} Haar features + integral image + AdaBoost cascade,
        enabling real-time face detection.
  \item \textbf{HOG + SVM (2005):} gradient histograms for pedestrian detection.
  \item \textbf{DPM (2010):} deformable part models for articulated objects.
\end{itemize}

\textbf{Limitation:} hand-crafted descriptors could not generalise across clutter,
viewpoint variation, or long-tail categories.

\begin{sectionbox}{TWO-STAGE DETECTORS}
\small
AlexNet (2012) proved CNNs could learn features from data, triggering the
\textbf{R-CNN family}:

\begin{itemize}
  \item \textbf{R-CNN:} selective search proposals $\rightarrow$ per-region CNN $\rightarrow$ SVM (slow).
  \item \textbf{Fast R-CNN:} shared conv backbone + RoI pooling (5--9$\times$ faster).
  \item \textbf{Faster R-CNN:} learnable RPN replaces search; near real-time at high mAP.
  \item \textbf{Mask R-CNN:} extends with a mask branch for instance segmentation.
\end{itemize}

\textbf{Trade-off:} highest mAP but per-proposal processing limits throughput.
\end{sectionbox}

% ---------------------------------------------------------------
\begin{sectionbox}{ONE-STAGE DETECTORS \& FOCAL LOSS}
\small
\textbf{Key insight:} skip the proposal stage; predict boxes \& classes at every
grid cell / anchor in a single forward pass.

\begin{itemize}
  \item \textbf{YOLO (2016):} grid-cell unified prediction; fastest family.
  \item \textbf{SSD (2016):} multi-scale feature maps handle object scale variation.
  \item \textbf{RetinaNet (2017):} Focal Loss addresses foreground--background imbalance:
    \( FL(p_t) = -\alpha_t(1-p_t)^\gamma \log p_t \)
  \item \textbf{YOLOv5--v9:} improved backbone (CSP, ELAN), neck (PANet), and head
        designs deliver state-of-the-art speed--accuracy.
\end{itemize}

\textbf{Trade-off:} 3--5$\times$ faster than two-stage; slightly lower mAP on
small, dense, or occluded objects.
\end{sectionbox}

% ---------------------------------------------------------------
\begin{sectionbox}{TRANSFORMERS: DETR \& SUCCESSORS}
\small
\textbf{DETR (2020):} recasts detection as \emph{direct set prediction}.
\begin{itemize}
  \item Fixed set of \textbf{object queries} attend over CNN feature maps.
  \item \textbf{Bipartite (Hungarian) matching} provides unique assignment during training.
  \item Eliminates hand-designed anchors and (in principle) NMS.
  \item \textbf{Drawback:} slow convergence; heavy compute on small objects.
\end{itemize}

\textbf{Key successors:} Deformable DETR, DAB-DETR, DINO-DETR (faster convergence,
multi-scale attention). \textbf{Grounding DINO} and \textbf{OWLv2} extend to
open-vocabulary detection via text--image alignment.
\end{sectionbox}

\begin{guidebox}
\small\textbf{Quick guide:}
\begin{itemize}
  \item \textbf{Edge / mobile / real-time:} YOLOv8n, YOLOv9s, MobileNet-SSD.
  \item \textbf{High-accuracy server inference:} Faster R-CNN w/ ResNet-101, YOLOv9-E.
  \item \textbf{Open-vocabulary / long-tail:} Grounding DINO, OWLv2.
  \item \textbf{Research / set-prediction elegance:} DETR, Deformable DETR.
\end{itemize}

\begin{sectionbox}{DEPLOYMENT CHECKLIST}
\small
Before shipping a detector to production, verify the following:

\begin{enumerate}
  \item \textbf{Latency budget:} measure end-to-end (pre-processing + inference + NMS),
        not just backbone FLOPs.
  \item \textbf{Input resolution:} higher resolution improves small-object recall but
        quadratically increases compute; profile on target hardware.
  \item \textbf{Batch size:} batch\,=\,1 latency for streaming; larger batches for
        offline throughput---tune separately.
  \item \textbf{NMS cost:} IoU-NMS is $O(n^2)$ in proposals; use batched NMS,
        Soft-NMS, or NMS-free heads (DETR) when $n$ is large.
  \item \textbf{Quantization / pruning:} INT8 post-training quantization (PTQ) typically
        retains $\sim$98\,\% mAP with 2--4$\times$ speedup on edge hardware;
        validate accuracy before deployment.
\end{enumerate}
\end{sectionbox}

% ---------------------------------------------------------------
\begin{sectionbox}{CONCLUSION}
\small

\begin{itemize}
  \item Object detection has progressed from hand-crafted sliding-window pipelines
        to end-to-end learned networks, achieving dramatic gains in both accuracy
        and speed on standard benchmarks.
  \item \textbf{Two-stage detectors} (Faster R-CNN family) remain the benchmark for
        highest accuracy but are constrained by per-proposal overhead.
  \item \textbf{One-stage detectors} (YOLO family) dominate real-time and edge
        deployment with competitive accuracy and simple pipelines.
  \item \textbf{Transformer-based detectors} (DETR family) eliminate anchors and NMS,
        enable open-vocabulary grounding, but require more compute and data.
  \item The \textbf{speed--precision frontier} continues to improve: YOLOv9-E
        achieves 55.6 mAP---matching earlier two-stage models---at real-time speed.
  \item \textbf{Future directions:} edge-optimised transformers, 3D/LiDAR-camera
        fusion, open-vocabulary grounding, and hardware-aware neural architecture
        search promise to further narrow the gap between speed and precision.
\end{itemize}
\end{sectionbox}
