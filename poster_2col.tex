% ---------------------------------------------------------
\begin{sectionbox}{INTRODUCTION}
\small
\textbf{Object detection} identifies \emph{what} is present in an image
and \emph{where} it is located, producing a variable-length set of
bounding boxes and class labels.

Its history is best understood as repeatedly navigating a core
trade-off:
\begin{itemize}
  \item \textbf{Precision (mAP):} fewer misses, fewer false alarms,
        tighter localisation.
  \item \textbf{Speed (FPS):} higher throughput and lower latency for
        real-time systems.
\end{itemize}

\textbf{Thesis:} Detectors evolved from hand-crafted features to
CNN-based pipelines, then to dense one-stage models and
transformer-based set prediction---each step reshaping the
speed--precision frontier.
\end{sectionbox}

% ---------------------------------------------------------
\begin{sectionbox}{TRADITIONAL METHODS (PRE-2012)}
\small
\textbf{Key idea:} engineer features $+$ scan every window.

\begin{itemize}
  \item \textbf{Viola--Jones:} Haar-like features $+$ integral image
        $+$ cascade for real-time face detection.
  \item \textbf{HOG+SVM:} gradient histograms outperformed Haar for
        pedestrian detection.
  \item \textbf{DPM:} part-based deformable models achieved state of
        the art pre-deep-learning.
\end{itemize}

\textbf{Limitation:} hand-crafted descriptors failed with occlusion,
pose variation, and long-tail appearances.
\end{sectionbox}

% ---------------------------------------------------------
\begin{sectionbox}{DEEP LEARNING ERA}
\small
\textbf{AlexNet (2012)} showed that features learned end-to-end from
data could outperform any hand-crafted pipeline.

\textbf{Two-stage detectors} (R-CNN $\rightarrow$ Fast R-CNN
$\rightarrow$ Faster R-CNN) achieve high precision by first proposing
candidate regions, then classifying and refining each region
independently. The Region Proposal Network (RPN) made proposals
fully differentiable and end-to-end learnable.

\textbf{One-stage detectors} (YOLO, SSD) treat detection as \emph{dense
prediction}: boxes and scores are predicted at every grid cell in a
single forward pass, dramatically increasing throughput.

\begin{sectionbox}{TRANSFORMERS: DETR \& ATTENTION}
\small
\textbf{DETR} (Carion et al., 2020) reframes detection as
\emph{direct set prediction}:
\begin{itemize}
  \item A fixed set of \textbf{object queries} attends to the entire
        feature map via a transformer decoder.
  \item \textbf{Hungarian matching} assigns predictions to ground-truth
        one-to-one during training, eliminating duplicate detections.
  \item In principle, no anchors and no NMS are required.
\end{itemize}

\textbf{Swin Transformer:} shifted-window attention provides
hierarchical, multi-scale features for dense prediction tasks with
linear complexity in the number of tokens.
\end{sectionbox}

\begin{sectionbox}{WHEN TO USE WHICH MODEL}
\small
\begin{itemize}
  \item \textbf{Real-time video / edge devices:}
        Use \textbf{YOLOv8-S/M} or \textbf{SSD-MobileNet}.
        Prioritise FPS; accept moderate mAP drop.
  \item \textbf{Crowded scenes / small objects:}
        Use \textbf{Faster R-CNN} $+$ FPN or
        \textbf{Cascade R-CNN}.
        Two-stage refinement handles scale variation better.
  \item \textbf{Safety-critical (medical, aviation):}
        Use \textbf{DETR} or ensemble methods.
        Prioritise precision and recall; latency is secondary.
  \item \textbf{Novel / open-vocabulary categories:}
        Use \textbf{Grounding DINO} or \textbf{OWL-ViT}.
        Text-image grounding generalises without per-class tuning.
  \item \textbf{Resource-constrained (IoT / mobile):}
        Use \textbf{YOLOv8-N} or a quantised SSD.
        Apply pruning $+$ INT8 post-training quantisation.
\end{itemize}
\end{sectionbox}

% ---------------------------------------------------------
\begin{sectionbox}{CONCLUSION \& FUTURE DIRECTIONS}
\small
\textbf{No universal best detector exists.}
Every deployment is a point on the speed--precision surface; the
right choice depends on latency budget, power envelope, required
recall, and the target domain.

\textbf{Key takeaways:}
\begin{itemize}
  \item Two-stage detectors remain the precision benchmark for
        difficult scenes.
  \item One-stage detectors dominate real-time applications and
        continue to close the accuracy gap rapidly.
  \item Transformer-based detectors eliminate anchor and NMS
        engineering at the cost of longer training.
\end{itemize}

\textbf{Emerging trends:}
\begin{itemize}
  \item \textbf{Edge AI / TinyML:} pruning, quantisation, knowledge
        distillation, hardware-aware NAS.
  \item \textbf{3D detection:} LiDAR--camera fusion, Bird's-Eye-View
        representations for autonomous driving.
  \item \textbf{Open-vocabulary:} vision--language grounding for
        zero-shot detection of novel categories.
\end{itemize}
\end{sectionbox}
