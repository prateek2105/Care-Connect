  \begin{contentbox}{Introduction}
    \small
    \textbf{Object detection} determines \emph{what} objects appear in an
    image and \emph{where} they are (bounding boxes + class labels).

    \smallskip
    The field has navigated a persistent trade-off:

    \begin{itemize}
      \item \textbf{Precision (mAP)} -- fewer missed detections and tighter boxes.
      \item \textbf{Speed (FPS)} -- real-time throughput and low latency.
    \end{itemize}

    \smallskip
    \textbf{Thesis.} Detectors evolved from hand-crafted features, through
    CNN-based two-stage and one-stage pipelines, to transformer-based set
    prediction---each generation reshaping the speed-precision frontier.
  \end{contentbox}

  \vspace{2mm}

  \begin{contentbox}{Traditional Methods (Pre-2012)}
    \small
    \textbf{Key idea:} engineer descriptors, then scan candidate windows.

    \smallskip
    \textbf{Milestones}
    \begin{itemize}
      \item \textbf{Viola--Jones (2001):} Haar features + integral image +
            Adaboost cascade; first real-time face detector.
      \item \textbf{HOG + SVM (2005):} gradient histograms for robust
            pedestrian detection.
      \item \textbf{DPM (2010):} deformable part models for articulated
            objects.
    \end{itemize}

    \smallskip
    \textbf{Limitation:} hand-crafted features plateaued against complex
    scenes, clutter, and long-tail appearance variation.
  \end{contentbox}

  \vspace{2mm}

  \begin{contentbox}{Transformers \& Attention}
    \small
    \textbf{DETR (2020)} reframes detection as \emph{direct set prediction}:

    \begin{itemize}
      \item Fixed set of \textbf{object queries} decoded from image features.
      \item \textbf{Bipartite matching} (Hungarian algorithm) assigns
            predictions to ground-truth during training.
      \item Eliminates hand-designed anchors and (in principle) NMS.
    \end{itemize}

    \smallskip
    \textbf{Swin Transformer (2021):} hierarchical windowed self-attention
    provides shift-invariant multi-scale features, serving as a strong
    backbone for both one- and two-stage detectors.
  \end{contentbox}

  \begin{contentbox}{Deep Learning: Two-Stage Detectors}
    \small
    \textbf{Paradigm shift (AlexNet, 2012):} CNNs learn features from data,
    outperforming all hand-crafted descriptors.

    \smallskip
    \textbf{Two-stage concept:}
    \begin{enumerate}[leftmargin=*, noitemsep, topsep=1pt]
      \item \textbf{Stage 1} -- propose candidate regions.
      \item \textbf{Stage 2} -- classify + refine each proposal.
    \end{enumerate}

    \textbf{R-CNN $\to$ Fast R-CNN $\to$ Faster R-CNN:} each step shared or
    accelerated computation. The \textbf{RPN} makes proposals fully
    learnable; the full network trains end-to-end.

    \smallskip
    \textbf{Trade-off:} high mAP, but per-proposal processing limits throughput.

    \vspace{2mm}

  \begin{contentbox}{One-Stage Detectors \& Focal Loss}
    \small
    \textbf{One-stage idea:} predict boxes + classes in a \emph{single pass},
    using dense anchors across the spatial grid.

    \begin{itemize}
      \item \textbf{YOLO (2016):} grid-cell prediction; fast but initially
            limited on small objects.
      \item \textbf{SSD (2016):} multi-scale feature maps for different
            object sizes.
      \item \textbf{RetinaNet (2017):} Focal Loss addresses foreground--background
            imbalance:
    \end{itemize}
    \[
      FL(p_t) = -\alpha_t(1-p_t)^\gamma \log p_t
    \]

    \vspace{2mm}

  \begin{contentbox}{Conclusion \& Future Directions}
    \small
    No single ``best'' detector exists; choice depends on deployment:
    \begin{itemize}
      \item \textbf{Speed-critical} (edge, video): one-stage (YOLOv8) with
            quantization and pruning.
      \item \textbf{Precision-critical} (medical, safety): two-stage or
            transformer-based detectors.
    \end{itemize}
    \textbf{Emerging:} Edge AI/TinyML, 3D LiDAR-camera fusion,
    open-vocabulary grounding (GLIP, Grounding DINO).
  \end{contentbox}
