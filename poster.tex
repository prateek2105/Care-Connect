\begin{secbox}{INTRODUCTION}
\small
\textbf{Object detection} identifies \emph{what} objects are present and \emph{where} they
are located (class label + bounding box) in a single image.
The field's 25-year history is a story of navigating one fundamental trade-off:

\begin{itemize}
  \item \textbf{Precision (mAP)} --- fewer misses, fewer false alarms, tighter localisation.
  \item \textbf{Speed (FPS)} --- real-time throughput for video, robotics, and edge devices.
\end{itemize}

\textbf{Key takeaway:} no single ``best'' detector exists; the right choice always depends
on whether the deployment prioritises \emph{speed} or \emph{precision}.
\end{secbox}

% ------------------------------------------------------------
\begin{secbox}{TRADITIONAL ERA \ (PRE-2012)}
\small
\textbf{Strategy:} exhaustive sliding-window search with hand-crafted descriptors and a
shallow classifier.

\begin{itemize}
  \item \textbf{Viola--Jones (2001):} Haar-like features + integral image + AdaBoost
        cascade; first real-time face detector.
  \item \textbf{HOG + SVM (2005):} oriented-gradient histograms tuned for pedestrian
        detection.
  \item \textbf{DPM (2008--10):} deformable part models handle pose variation via
        latent-SVM.
\end{itemize}

\textbf{Limitation:} brittle to out-of-distribution appearance; sliding-window cost scales
poorly with image resolution.
\end{secbox}

% ------------------------------------------------------------
\begin{secbox}{DEEP LEARNING: TWO-STAGE DETECTORS \ (2014--)}
\small
\textbf{Trigger:} AlexNet (2012) showed that CNN features learned from data outperform
any hand-crafted descriptor.

\textbf{Two-stage pipeline:}
\begin{enumerate}
  \item Generate \emph{region proposals} (candidate boxes).
  \item Classify and refine each proposal with a CNN head.
\end{enumerate}

\begin{itemize}
  \item \textbf{R-CNN $\to$ Fast R-CNN:} per-region CNN features $\to$ shared conv.\
        backbone + RoI pooling.
  \item \textbf{Faster R-CNN (2015):} Region Proposal Network (RPN) makes proposals
        fully learnable; end-to-end training at $\approx$26~FPS / 42~mAP.
\end{itemize}

\textbf{Trade-off:} high accuracy, but per-proposal computation bottlenecks throughput.
\end{secbox}

% ------------------------------------------------------------
\begin{secbox}{ONE-STAGE DETECTORS \ (2016--PRESENT)}
\small
\textbf{Idea:} dense prediction in a single forward pass --- no separate proposal stage.

\begin{itemize}
  \item \textbf{YOLO (2016):} unified grid-based regression; $\approx$45~FPS with reduced
        accuracy on small objects.
  \item \textbf{SSD (2016):} multi-scale anchor predictions; faster, weaker on small
        objects.
  \item \textbf{RetinaNet (2017):} Focal Loss
        $FL = -\alpha_t(1-p_t)^{\gamma}\log p_t$
        cures the foreground/background imbalance that hampered earlier one-stage models.
  \item \textbf{YOLOv5--v8 (2020--23):} anchor-free heads, task-aligned assignment;
        state-of-the-art real-time performance.
\end{itemize}
\end{secbox}

% ------------------------------------------------------------
\begin{secbox}{TRANSFORMERS: SET PREDICTION \ (2020--)}
\small
\textbf{DETR (2020):} reformulates detection as \emph{direct set prediction}.

\begin{itemize}
  \item Learnable \textbf{object queries} attend globally to encoded image features via a
        Transformer encoder--decoder.
  \item \textbf{Hungarian matching} during training provides duplicate-free, one-to-one
        assignments --- no need for NMS at inference.
  \item Slow to converge on COCO; Deformable DETR, DN-DETR, and DINO-DETR close the gap.
\end{itemize}

\textbf{Swin Transformer (2021):} hierarchical windowed attention yields multi-scale
features competitive with FPN-based CNN backbones.
\end{secbox}

\begin{secbox}{FUTURE DIRECTIONS}
\small
\begin{itemize}
  \item \textbf{Edge AI / TinyML:} structured pruning, INT8 quantisation, and knowledge
        distillation for mobile and embedded deployment.
  \item \textbf{3-D \& multi-modal:} LiDAR--camera fusion and Bird's-Eye-View (BEV)
        representations for autonomous driving.
  \item \textbf{Open-vocabulary detection:} text-guided grounding (GLIP, Grounding DINO)
        enables detecting arbitrary, unseen categories without per-class training.
  \item \textbf{Self-supervised pre-training:} DINO/CLIP-style features reduce annotation
        burden for downstream detectors.
\end{itemize}
\end{secbox}

% ------------------------------------------------------------
\begin{secbox}{CONCLUSION}
\small
Object detection evolved from \emph{hand-crafted exhaustive search} (Viola--Jones,
HOG+SVM) through \emph{deep two-stage pipelines} (R-CNN family) and
\emph{real-time one-stage predictors} (YOLO, SSD, RetinaNet) to
\emph{transformer-based set prediction} (DETR).  Each transition expanded the
speed--precision Pareto frontier outward.

\smallskip
\textbf{Practical guidance:}
\begin{itemize}
  \item \textbf{Latency-sensitive} (video analytics, robotics) $\to$ YOLOv8.
  \item \textbf{Accuracy-critical} (medical imaging, surveillance) $\to$ Faster R-CNN or
        a DETR variant.
  \item \textbf{Novel-category generalisation} $\to$ open-vocabulary detectors.
\end{itemize}
\end{secbox}
